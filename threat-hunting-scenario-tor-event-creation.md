# Threat Event (Unauthorized TOR Usage)
**Unauthorized TOR Browser Installation and Use**

## Steps the "Bad Actor" Took to Create Logs and IoCs:
1. Downloaded the TOR Browser installer from the official TOR Project website.
2. Executed the TOR Browser portable installer:
   ```text
   tor-browser-windows-x86_64-portable-15.0.19.exe
   ```
3. Extracted the TOR Browser files to the Desktop.
4. Opened the TOR Browser from the Desktop.
5. Connected to the TOR network and generated network activity.
6. Created a file named:
   ```text
   tor-shopping-list.txt
   ```
7. TOR-related file, process, and network activity was captured for investigation.

---

## Tables Used to Detect IoCs:

| **Parameter** | **Description** |
|---|---|
| **Name** | DeviceFileEvents |
| **Purpose** | Used to detect the TOR installer, extracted TOR-related files, shortcuts, browser profile files, and the creation of the tor-shopping-list.txt file. |

| **Parameter** | **Description** |
|---|---|
| **Name** | DeviceProcessEvents |
| **Purpose** | Used to detect execution of the TOR installer, firefox.exe processes associated with TOR Browser, and the tor.exe service. |

| **Parameter** | **Description** |
|---|---|
| **Name** | DeviceNetworkEvents |
| **Purpose** | Used to detect network activity generated by tor.exe and firefox.exe, including TOR-related connections over ports such as 9001 and 9150. |

## Related Queries:

```kql
// Detect TOR-related files on the endpoint
DeviceFileEvents
| where DeviceName == "aiden-threat-hu"
| where InitiatingProcessAccountName == "ligrado"
| where FileName contains "tor"
| where Timestamp >= datetime(2026-08-12T17:58:11.0237467Z)
| order by Timestamp desc
| project Timestamp, DeviceName, ActionType, FileName, FolderPath, SHA256, InitiatingProcessAccountName
```

```kql
// Detect execution of the TOR Browser installer
DeviceProcessEvents
| where DeviceName == "aiden-threat-hu"
| where ProcessCommandLine contains "tor-browser-windows-x86_64-portable-15.0.19.exe"
| project Timestamp, DeviceName, AccountName, ActionType, FileName, FolderPath, SHA256, ProcessCommandLine
```

```kql
// Detect TOR Browser or TOR service execution
DeviceProcessEvents
| where DeviceName == "aiden-threat-hu"
| project Timestamp, DeviceName, AccountName, ActionType, FileName, FolderPath, SHA256, ProcessCommandLine
| where FileName has_any ("tor.exe", "firefox.exe", "tor-browser.exe")
| order by Timestamp desc
```

```kql
// Detect TOR-related network connections
DeviceNetworkEvents
| where DeviceName == "aiden-threat-hu"
| where InitiatingProcessAccountName != "system"
| where InitiatingProcessFileName in ("tor.exe", "firefox.exe")
| where RemotePort in ("9001", "9030", "9040", "9050", "9051", "9150")
| project Timestamp, DeviceName, InitiatingProcessAccountName, ActionType, RemoteIP, RemotePort, RemoteUrl, InitiatingProcessFileName
| order by Timestamp desc
```

```kql
// Detect creation or modification of the TOR shopping list
DeviceFileEvents
| where FileName contains "shopping-list.txt"
```

## Investigation Results:

The investigation confirmed that TOR Browser was installed and used on the endpoint `aiden-threat-hu` by the user `ligrado` on August 12, 2026.

The TOR Browser portable installer was executed from the user's Downloads directory and extracted TOR Browser files to the Desktop. Subsequent process telemetry showed execution of both `firefox.exe` and `tor.exe`.

Network telemetry confirmed TOR activity, including the browser communicating with the local TOR SOCKS proxy at:

```text
127.0.0.1:9150
```

The `tor.exe` process also established successful external network connections, including:

```text
157.180.78.167:9001
```

Additional TOR-related connections over port 443 were observed.

TOR Browser was later launched again, producing another set of TOR Browser processes and network connections.

---

## Response Taken:

TOR Browser usage was confirmed on endpoint `aiden-threat-hu` by user `ligrado`.

The endpoint was isolated and the user's direct manager was notified.
